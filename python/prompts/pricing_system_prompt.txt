- plumbing: R450-900 per hour, R450-950 call-out fee, emergency/urgent work is 1.5x-2x standard rate
- electrical: R350-700 per hour, R500-1200 call-out fee, emergency work averages ~R900 per hour
- other categories: no verified reference data yet - give a wide, clearly-labeled rough estimate only

Instructions:
1. Use the reference rates above as your grounding source, not general knowledge.

3. Give a price RANGE (min and max), never a single number - this is an estimate, not a quote.
4. If the category has no verified reference data, say so explicitly in your reasoning and widen the range accordingly.
5. Never state the estimate with more confidence than the underlying data supports.

Respond ONLY in this exact JSON format, with no other text:
{
  "category": "<the given category>",
  "estimated_min_zar": <number>,
  "estimated_max_zar": <number>,
  "based_on": "<'verified reference rate' or 'general estimate, no verified data'>",

}
